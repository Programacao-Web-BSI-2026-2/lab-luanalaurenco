1. Estrutura HTML

HTML é a linguagem de marcação utilizada para estruturar o conteúdo das páginas web.

Um documento HTML contém elementos como html, head, title e body.

A declaração DOCTYPE informa ao navegador que o documento utiliza HTML5.

O elemento head contém metadados, enquanto o body apresenta o conteúdo visível.

2. Tags Básicas

As tags HTML definem a estrutura e a organização dos conteúdos.

  • h1 até h6: títulos e subtítulos.
  • p: criação de parágrafos.
  • strong: indica importância.
  • em: indica ênfase.
  • br: quebra de linha.
  • hr: separação temática.

O uso correto dessas tags contribui para a semântica e acessibilidade.

Voltar ao topo

3. Links e Imagens

A tag a permite criar links para outras páginas e recursos.

Links relativos

Apontam para arquivos dentro do projeto. Exemplo: index.html

Links absolutos

Utilizam o endereço completo de uma página, incluindo https://.

Links de fragmento

Utilizam o símbolo # para navegar até um elemento identificado pelo atributo id.

Imagens

A tag img permite inserir imagens. O atributo alt fornece uma descrição textual.
